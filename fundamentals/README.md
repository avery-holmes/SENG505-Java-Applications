# Java Fundamentals

These smaller assignments document the early part of my SENG 505 progression. They are not intended to be flagship portfolio projects; they show the foundational work that preceded the larger data-structure and simulation assignments.

| Exercise | Focus |
| --- | --- |
| [Number Converter](number-converter/) | string parsing, numeric conversion, arithmetic |
| [Coin Flip Probability](coin-flip-probability/) | probability calculation, loops/methods |
| [Right Triangle](right-triangle/) | random values, arithmetic, `Math` library |
| [Vending Machine Change](vending-machine-change/) | integer arithmetic and remainders |
| [RIAA Fine Calculator](riaa-fine-calculator/) | input, arithmetic, formatted output |

Several other course exercises depended heavily on instructor-provided classes or sample programs. I intentionally left those out of this public portfolio rather than present supporting code I did not author as my own.
