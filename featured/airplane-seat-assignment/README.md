# Airplane Seat Assignment

An interactive seating simulation for a 13-row airplane divided into first, business, and economy class sections. The application validates ticket type and seat input before assigning a seat and redisplaying the seating chart.

## Concepts
- two-dimensional arrays
- string parsing and normalization
- boundary/range validation
- exception handling
- repeated user interaction with loops
- state mutation and immediate feedback

## Run
```bash
cd src
javac AirplaneSeats.java
java AirplaneSeats
```
