# Recursive Palindrome Checker

A palindrome checker built around a recursive method rather than an explicit stack. The program normalizes user input and evaluates characters from the outside inward until a base case is reached.

## Concepts
- recursion
- base and recursive cases
- string normalization
- input/output

## Run
```bash
cd src
javac PalindromeAssignment.java
java PalindromeAssignment
```

## Why include both palindrome projects?
The recursive and stack implementations show two different ways to reason about the same problem: one through the call stack and one through an explicit collection.
