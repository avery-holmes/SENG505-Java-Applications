# Palindrome Checker with Stacks

A console palindrome checker implemented with Java stacks. User input is normalized before characters are pushed and compared.

## Concepts
- `Stack`
- input normalization
- LIFO behavior
- algorithmic comparison
- defensive user input handling

## Run
```bash
cd src
javac PalindromeStack.java
java PalindromeStack
```

This is Program Set 2 Part C and complements the recursive palindrome implementation elsewhere in this repository.
